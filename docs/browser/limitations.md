# Phase 18 limitations

This is a read-only browser foundation, not Phase 18 completion. Missing: durable asynchronous browser jobs/sessions, strategy registry, official API connectors, Browser Use, Hermes, computer-use/desktop control, login and human takeover, form drafting, approval UI, downloads/uploads, screenshots, cancellation/recovery, work-manager/task integration, cost quotas, audit events, and realtime progress. There is no OS/network sandbox; do not expose the worker beyond a private loopback or separately firewalled network.
