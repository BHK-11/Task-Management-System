# Objectives and key results

OKRs are personal to the signed-in account. An `OkrCycle` contains a name and inclusive start/end dates; an `Objective` belongs to one cycle and may reference an owned goal; a `KeyResult` defines a quantitative baseline, target, unit, and direction. They are separate records rather than duplicate goals or tasks.

The owner creates cycles through objective creation. Matching owner/name/start/end values reuse one cycle. Objectives have explicit active/completed/cancelled status. Status is not inferred from a score. Key results support increasing or decreasing targets and retain their measurement history.

Routes: `/okrs`, `/okrs/new`, `/okrs/{id}`. The system does not create fictional key results, team-shared OKRs, approvals, or AI confidence estimates.
